# Команда «Ценолова»

Роли подобраны и переписаны под этот проект по мотивам шаблона
[Claude Code Game Studios](https://github.com/Donchitos/Claude-Code-Game-Studios) (MIT, © 2026 Donchitos).

| Роль | Когда звать |
|---|---|
| product-director | что делать дальше, разбор продукта |
| producer | план и оценка большой задачи |
| ux-designer | экраны Mini App на iPhone |
| lead-programmer | ревью кода, архитектура, лимиты D1 |
| qa-tester | поиск багов перед выкладкой |
| security-engineer | аудит безопасности |
| ops-engineer | cron, сборщик, D1, выкладка |
| community-manager | посты и рубрики канала |
| prompter | **каждая идея владельца** — сначала сюда: вопросы простыми словами и точное задание |

Пример: «собери команду: продакт, дизайнер и тестировщик — разберите вкладку Сделки».

## Как проходит каждая идея
Любая идея Эльдара и любое его «да» на моё предложение идут через `prompter` (два хода):
1. `prompter` разбирает идею, читает код, задаёт не больше 3–5 вопросов с готовыми вариантами и режимом «не знаю — решу сам»;
2. после ответов выдаёт точное задание (цель, что увидит владелец, шаги, что решено самим, крайние случаи, проверка);
3. исполнитель делает ровно по заданию и сверяется с пунктом «как проверить».
Исключения: опечатки, прямой вопрос («проверь», «где это ставить»), срочное исправление поломки — без промтовика.
