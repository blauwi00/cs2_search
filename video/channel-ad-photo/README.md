# Реклама канала на фото стола

1. `npx hyperframes render -o out/screen.mp4` — только экран (920×518).
2. Фото стола — `assets/desk.jpg` (в репозиторий не кладётся). Углы экрана на фото ×3 (1920×1440): TL 294,87 · TR 1215,282 · BR 1212,756 · BL 306,822.
3. Склейка ffmpeg: экран вписывается по перспективе (perspective sense=destination) в маску-многоугольник, комната затемняется, отсвет экрана — размытая копия только экрана; медленный наезд камеры, подпись POV сверху. Итог 1080×1350 (4:5) для Telegram.
