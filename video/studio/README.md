# Студия монтажа роликов «Ценолова»

Как в схеме «ИИ-монтажёр»: Claude монтирует ролики открытыми инструментами по твоим примерам и исходникам.

| Папка | Что класть |
|---|---|
| `референсы/` | ролики, стиль которых нравится (скачивает Claude через yt-dlp или присылаешь файлом) |
| `исходники/` | твои записи: говорящая голова, экран телефона, озвучка ElevenLabs |
| `готовое/` | готовые ролики 9:16 для TikTok / Shorts / Reels |

Инструменты (ставятся в облачной среде `cs2_search`):
- **HyperFrames** — анимация сцен (HTML → MP4), уже используется в `video/promo` и `video/series`;
- **Remotion** — графика на React, если нужен сложный моушн;
- **FFmpeg** — нарезка, вырезание пауз, склейки, звук;
- **Whisper** (модель small, русский) — субтитры по словам из речи;
- **yt-dlp** — скачать референсы по ссылке.

Порядок работы:
1. «Изучи стиль роликов из `референсы/`: шрифты, цвета, субтитры, склейки, темп, графику, звук. Собери брендбук» → `brandbook.md`.
2. «Смонтируй ролик из файла в `исходники/`: вырежи паузы, следуй брендбуку, добавь субтитры, графику и музыку. Сначала покажи раскадровку, потом экспортируй в `готовое/`».

Большие исходники в репозиторий не коммитятся (см. .gitignore) — присылай их в чат.
