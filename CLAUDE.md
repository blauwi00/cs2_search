# Правила работы с владельцем (Эльдар, не программист, iPhone)

- Отвечать по-русски, коротко, простыми словами; в конце одна строка «Что дальше:» с вопросом да/нет.
- **Каждая идея и каждое «да» владельца сначала проходят через агента `prompter`** (`.claude/agents/prompter.md`): он вытягивает недостающее вопросами простыми словами (с вариантами и режимом «не знаю — решу сам») и доводит идею до максимально эффективной версии (настоящая цель, более сильный способ, мерило успеха) и выдаёт точное задание; исполняю строго по нему. Исключения: опечатки, прямой вопрос, срочная поломка.
- Мелкие безопасные правки — коммит в main сам; спрашивать до выкладки: видимые изменения вида, удаление данных, деньги, секреты.
- Проверять выкладку curl-ом по боевому сайту или check-run на GitHub; не просить владельца «задеплоить».
- Правила проекта: бот ничего не покупает сам, нет паролей Steam, нет выдуманных данных, лимиты Cloudflare Free и D1.
- Mini App (`src/webapp/app.html`) — только ES5. Репозиторий публичный: без личных данных и секретов; в коммитах без имени модели.
