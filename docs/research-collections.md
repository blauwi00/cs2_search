# Закупка коллекций: что известно (исследование 12.11.2026)

Статус источников: почти всё — блоги маркетплейсов и обзорники (у них есть интерес). Цифры доходности НЕ проверены.
Проверено по первоисточнику только одно: Valve не пишет про ротации в заметках об обновлениях (последние 10 заметок
https://steamcommunity.com/games/CSGO/rss/ без слов про коллекции/дроп-пул). Ротации находят по датамайну и трекерам.

## Что двигает цену коллекции
1. Вылет из недельного дроп-пула: новые копии перестают появляться. Пример (по обзорам, не проверено по патчноутам):
   - 31.03.2025: добавлены Ascent, Boreal, Radiant; убраны Bank, Italy, Lake, Train.
   - 21.01.2026: добавлены Harlequin, Achroma; убраны Dust 2, Inferno 2018, Nuke 2018, Safehouse.
     white.market: P250 Sand Dune +520% (коллекцию не называет — связь с убранными лишь предположение).
   - 03.2026: Recoil Case заменён на Dead Hand Terminal. Genesis вошёл в 09.2025 (вместо Fracture).
   - Редкий пул (rare drop pool) пуст с декабря 2025 / января 2026 (даты в источниках расходятся).
2. Контракты обмена с 22–23.10.2025: 5 красных (Covert) -> нож/перчатки той же коллекции.
   Ножи и перчатки подешевели на 30–60%, «топливо» (дешёвые красные) подорожало, рынок потерял $1–3 млрд (оценки расходятся).
   Спрос на красные скины конкретной коллекции зависит от того, какие ножи/перчатки в её пуле и сколько они стоят.
3. Новые коллекции в дропе давят цены старых (white.market).

## Риски
- Valve меняет правила без предупреждения (октябрь 2025). «Дефицит» в 2025 был поставлен под сомнение (csdb.gg, один источник).
- После первого скачка цена может «стоять» месяцами: запасы продаются (skin.club).
- Покупать после объявления = платить надбавку: скачок за часы/сутки.
- Рост «15–30% в год» из блогов ничем не подтверждён.

## Нет данных
- Про DEZ в открытых источниках ничего нет — его схему можно только реконструировать по описанию владельца.
- Нет проверенных цифр «цена до/после» ротации: у трекеров (30/90/180/365 дней) они есть, но недоступны отсюда.
  Steam price history требует входа в аккаунт (владелец отказался); у бота своя история только с момента запуска.

## Что может бот (без выдумок)
1. Сигнал ротации: коллектор уже читает GitHub (датамайн) — ловить изменение списка дроп-пула и слать алерт сразу.
2. Экран «Коллекции»: статус (в дропе / убрана + дата), число предметов, динамика цены 7/30 дней по нашим снимкам и истории Skinport.
3. Кандидаты на вылет: коллекции дольше всех в пуле (эвристика «самая старая уходит первой» — слабая, помечать как гипотезу).
4. Топливо контрактов: для коллекции — цена 5 красных против стоимости ножей/перчаток пула; показывать только расчёт, без обещаний.
